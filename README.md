# Глобальная Карта — Гильдия Авантюристов

Локальное приложение для мета-игры D&D: кланы оформляют контракты, авантюристы выбирают выгодные предложения, Гильдия участвует в жизни мира, а операции автоматически симулируются по этапам.

## Локальный запуск

Требуется Node.js 22.12+.

```powershell
npm install
npm run dev
```

После запуска откройте адрес, показанный Vite в терминале (обычно `http://localhost:3000`). API-ключи и внешние сервисы приложению не нужны.

## Проверка и сборка

```powershell
npm run lint
npm test
npm run build
```

Готовая браузерная сборка появляется в `dist`; те же файлы используются Windows-оболочкой.

## Windows-приложение

```powershell
# Собрать и открыть desktop-версию
npm run desktop:dev

# Создать установщик и portable-версию
npm run desktop:win
```

Готовые файлы появляются в `release`:

- `GlobalMap-Setup-0.6.0-x64.exe` — обычный установщик;
- `GlobalMap-Portable-0.6.0-x64.exe` — переносимая версия без установки.

Приложение не подписано коммерческим сертификатом, поэтому Windows SmartScreen может показать предупреждение при первом запуске локальной сборки.

## Данные и настройка

- `src/data/default-clans.json` — стартовые кланы и Гильдия.
- `src/data/default-adventurers.json` — стартовые NPC-авантюристы.
- `public/media/GlobalMap.webp` — карта по умолчанию.
- `public/effects/AmbientFog001_001_Loop_White_1200x1200.webm` — атмосферный туман регионов.
- `public/themes` — темы интерфейса. После добавления CSS-файла выполните `npm run sync-themes` или перезапустите приложение.
- Приложение запускается с главного меню. Раздел «Игра» предлагает продолжить кампанию, начать новую или открыть `.globalmap`.
- Редакторы текущих авантюристов и событий изменяют активную кампанию, доступны только в режиме ГМа и открываются из верхней панели рядом с названием Гильдии.
- Главное меню содержит три файловых редактора для `adventurers.json`, `events.json` и `scenario.json`. Они открывают и скачивают самостоятельные наборы, не изменяя активную кампанию.
- Мастер новой игры проверяет выбранные JSON целиком, позволяет отдельно заменить списки авантюристов и событий, выбрать карту и только затем создаёт кампанию первого дня.
- В настройках ГМа файл `.globalmap` сохраняет сценарий вместе с изображением карты и открывает его на другом компьютере как новую кампанию.
- Кнопка «Регионы» в режиме ГМа открывает редактор границ, подписей, цветной заливки и атмосферного тумана. Новые регионы скрыты от игроков по умолчанию и сохраняются в сценариях.

## Короткий цикл игрового дня

1. Кланы разведывают донесения и создают контракты.
2. Рынок автоматически распределяет NPC по наиболее выгодным доступным контрактам.
3. Гильдия выполняет собственные действия. После этого составы и контракты фиксируются до симуляции.
4. Обычные операции симулируются автоматически, сюжетные миссии ожидают ручного рапорта ГМа.
5. ГМ проверяет рапорты и начинает следующий день.

Невыполненный контракт живёт до истечения связанного донесения. Тогда возвращаются оплата и вложенные ресурсы, но комиссия Гильдии удерживается. Успех и провал фактически начатой операции закрывают событие окончательно.

## Форматы файлов

- `adventurers.json` — самостоятельный список авантюристов;
- `events.json` — самостоятельный список событий и зависимостей;
- `scenario.json` — настройки сценария без вложенного изображения;
- `.globalmap` — переносимый сценарий с изображением карты;
- JSON-сейв — текущее состояние одной кампании.

Файлы проверяются по типу и версии. Файловые редакторы главного меню не изменяют текущую кампанию; кнопки «Авантюристы» и «События» в верхней панели ГМа редактируют именно активную игру.
